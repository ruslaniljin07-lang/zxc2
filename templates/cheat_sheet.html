1. Переменные и print() 
# создаём переменные
name = "Артур"
age = 100

# выводим на экран
print(name)
print("Возраст:", age)

# f-строка: подставляем значения
print(f"Меня зовут {name}, мне {age}")

Знак = — это «положи значение в переменную».

🎯 Зачем это нужно

Переменные хранят данные: имя, числа, итоги. Без них каждая программа — просто разовое действие. С ними одна запись пригодится в сотне мест.

💼 Где применяется

Любая программа: от консольных скриптов до веб-сервисов. Простой пример — калькулятор стоимости заказа: цена, количество и скидка лежат в переменных, а print выводит чек.

🌱 Мотивация

print() — твой первый способ поговорить с компьютером. Умеешь выводить — умеешь проверять всё, что пишешь.

2. Ввод данных input() 
# input() всегда даёт СТРОКУ
name = input()

# чтобы считать число — оберни в int()
age = int(input())
height = float(input())

print(age + 1)  # числа можно складывать

Ошибка ValueError? Значит, ввели не число.

🎯 Зачем это нужно

Программа становится интерактивной: спрашивает у человека и работает с его ответом. Это мостик между кодом и реальным миром.

💼 Где применяется

Формы регистрации, игры с запросом имени, боты в мессенджерах, программы-викторины. В любом тесте на ЕГЭ и олимпиадах ввод — стандарт.

🌱 Мотивация

Программа, которая читает данные — уже не игрушка, а инструмент. Свой первый интерактивный диалог ты соберёшь прямо сейчас.

3. Условия if / elif / else 
x = 7

if x > 10:
    print("много")
elif x == 7:
    print("семь!")
else:
    print("мало")

# сравнения: ==  !=  >  <  >=  <=
if x > 0 and x % 2 == 0:
    print("чётное положительное")

Не забывай двоеточие : и отступы (4 пробела).

4. Циклы for и while 
# for — повтори N раз
for i in range(5):
    print(i)          # 0 1 2 3 4

print(range(1, 11))   # от 1 до 10

# while — пока условие верно
n = 3
while n > 0:
    print(n)
    n -= 1   # не забудь изменить n!

break — выйти, continue — следующий шаг.

🎯 Зачем это нужно

Повторять действия без копипасты. Обработать тысячу строк — три строчки цикла, а не тысяча копий кода.

💼 Где применяется

Обработка таблиц и логов, генерация отчётов, проверка каждого товара в корзине, парсеры сайтов. Бухгалтерия, аналитика, админки — всё на циклах.

🌱 Мотивация

Ты перестаёшь «переписывать» — начинаешь «объяснять машине, что делать». Это и есть мышление программиста. Колёсики циклов крутят весь код вокруг тебя.

5. Списки 
fruits = ["яблоко", "банан"]

fruits.append("груша")   # добавить
print(len(fruits))        # сколько
print(fruits[0])          # первый

for fruit in fruits:
    print(fruit)

nums = [3, 1, 4]
print(sum(nums))    # 8
print(max(nums))    # 4
print(5 in nums)    # False
🎯 Зачем это нужно

Хранить коллекцию: пусть будет не одна переменная, а много элементов под одной «полкой». Обрабатывать всё разом проще.

💼 Где применяется

Корзина покупок, список студентов, логи сервера, очередь задач. Почти любая обработка данных начинается со списка.

🌱 Мотивация

Списки — это база. Разобрался со списками — половина ЕГЭ по информатике перестаёт пугать. Плюс это самый «рабочий» инструмент аналитика.

6. Строки 
s = "Hello World"

print(len(s))       # 11
print(s.upper())   # HELLO
print(s.split())   # ["Hello","World"]
print(s[0])         # первый символ
print(s[::-1])      # наоборот
print(" ".join(["a","b"]))
🎯 Зачем это нужно

Мир — это тексты: почта, отчёты, сайты, документы. Строки позволяют чистить, резать, склеивать и искать в них.

💼 Где применяется

Парсинг данных, лог-файлы, проверка email, боты, SEO-анализ. Каждая веб-страница — гигантская строка до обработки.

🌱 Мотивация
7. Функции def / return 
# def — объявляем, return — возвращаем
def square(x):
    return x * x

def greet(name):
    return f"Привет, {name}!"

result = square(5)
print(result)      # 25

Функция без return возвращает None.

🎯 Зачем это нужно

Один раз написал — используешь везде. Код становится короче, а баги — заметнее, ведь логика живёт в одном месте.

💼 Где применяется

Библиотеки, API, структура любого серьёзного проекта. «Перевести рубли в доллары», «проверить пароль», «посчитать метрику» — это всё функции.

🌱 Мотивация

Умение дробить задачу на маленькие функции — золотой навык. Это и есть DRY: Don't Repeat Yourself. Наниматели ищут именно такой код.

8. Ошибки try / except 
try:
    n = int(input())
except ValueError:
    n = 0          # запасной вариант
print(n)

try:
    print(10 / 0)
except ZeroDivisionError:
    print("На ноль делить нельзя")
🎯 Зачем это нужно

Программа не должна «падать» при ошибке. try/except ловит проблему и делает так, чтобы работа продолжилась по-умному.

💼 Где применяется

Любой ввод от пользователя, работа с сетью и файлами, внешние сервисы. В продакшене без обработки ошибок — никуда.

🌱 Мотивация

Ошибка — не конец, а сигнал, что подумать ещё раз. Программист, который спокойно пишет except, выглядит в разы надёжнее новичка, который нервничает на каждом исключении.

9. Генераторы и модули 
# список в одну строку
squares = [x ** 2 for x in range(5)]
evens = [x for x in range(10) if x % 2 == 0]

import math
print(math.sqrt(16))    # 4.0

import random
n = random.randint(1, 10)
🎯 Зачем это нужно

Кратко строить списки фильтрами и пользоваться готовыми решениями из модулей вместо изобретения велосипеда.

💼 Где применяется

Аналитика (посчитать среднее в одну строку), случайные данные для тестов, математические расчёты, научные вычисления.

🌱 Мотивация

Это «профессиональный вкус»: писать мощно и лаконично. Такой код читается как стих — и именно его разбирают на собеседованиях.

Строки — самая частая сущность в реальном коде. Один-два приёма на срезы — и задачи, где «наоборот/убрать/заменить», решаются в три строчки.

🎯 Зачем это нужно

Программа принимает решения. Без if код просто выполняет строчки по порядку — с if он «думает» и реагирует на ситуацию.

💼 Где применяется

Проверка пароля, скидки по возрасту, правила модерации, фильтры поиска. В реальной работе «если покупатель накопил 1000 баллов — начисли бонус» — тоже if.

🌱 Мотивация

Задачи на if — самые частые в ЕГЭ. Один раз понял — зубришь приёмы, а не код. Твой мозг уже так думает, осталось перевести на Python.
